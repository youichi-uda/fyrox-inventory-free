# fyrox-inventory-free

Core inventory system for the [Fyrox](https://fyrox.rs) game engine.

## Features

- Item definitions with rarity, category, weight, stacking, tags
- Item database resource (.itemdb files)
- Fixed-size inventory grid with stacking, splitting, merging, sorting
- Equipment system with slot type validation
- `InventoryHolder` and `ItemPickup` scripts
- Full Visit/Reflect/Serde support

## Pro Version

[fyrox-inventory-pro](https://youichi-uda.itch.io/) adds drag & drop UI widgets, inventory panels, and item tooltips.
